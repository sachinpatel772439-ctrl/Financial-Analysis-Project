# Financial Analysis Project

## Project Overview
This project focuses on analyzing financial data to understand sales performance, profitability, product performance, country-wise performance, and business trends.

The project uses Python, Pandas, NumPy, Matplotlib, Seaborn, MySQL, SQL, and Power BI to clean, analyze, visualize, and present financial data.

## Project Objectives
- Analyze overall sales and profit.
- Identify top-performing countries and products.
- Analyze segment-wise sales performance.
- Understand monthly sales trends.
- Calculate key financial KPIs.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- SQL
- Power BI

## Dataset Information
- Dataset: Financials.csv
- Total Records: 700
- Total Columns: 16

## Data Cleaning
- Cleaned column names.
- Converted financial columns into numeric format.
- Handled missing values.
- Converted date column into date format.
- Checked duplicate records.
- Created cleaned and analysis-ready datasets.

## Key Performance Indicators (KPIs)
- Total Sales: 118.73M
- Total Profit: 16.89M
- Total Units Sold: 1.13M
- Profit Margin: 14.23%

## Key Business Insights
- USA recorded the highest total sales.
- France recorded the highest total profit.
- Mexico recorded the lowest total sales.
- Paseo was the top-performing product by sales and profit.
- Carretera recorded the lowest product sales.
- The Small Business and Government segments contributed significantly to sales.

## SQL Analysis

- Year-wise performance.

- Segment-wise performance.
